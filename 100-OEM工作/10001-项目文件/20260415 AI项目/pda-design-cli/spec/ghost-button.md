# 幽灵按钮 (Ghost Button)

## 结构

直接使用 `<p>` 标签作为按钮载体，无额外外层容器，通过行内样式定义文本样式。

## 状态

### Default

| 属性 | 数值 |
|------|------|
| 背景色 | 无 |
| 文字颜色 | `#6445D1` |
| 字号 | `20px` |
| 字体 | `PingFang SC` |
| 行高 | `28px` |
| 文本对齐 | 右对齐 |
| 边框/内边距 | 无（依赖父容器布局） |

### Tap（推断）

- 文字颜色加深为 `#432CB0`
- 可添加下划线（`text-decoration: underline`）或背景色 `#F1E7FF`（10%透明度）增强交互反馈

### Disabled（推断）

- 文字颜色 `#A086E3`（主色淡化）
- 透明度 `opacity: 0.5`
- 禁用点击（`pointer-events: none`）

## 代码要求

- 使用语义化类名（如 `.btn-ghost`），避免行内样式。
- 通过 CSS 类统一管理状态（`:hover` / `:disabled`）。
- 补充内边距（如 `padding: 8px 16px`）提升可点击区域。
