# 分割线 (Divider)

分割线用于在内容区块之间建立视觉分隔，帮助用户快速识别信息层级。

---

## 1. 组件概述

分割线是一条水平线，用于分隔不同内容区块或内容类型。支持实线和虚线两种样式，适用于不同的视觉场景。

---

## 2. 基础样式规范

| 属性 | 数值 | 说明 |
|------|------|------|
| **颜色** | `#F5F5F5` | Black NO.2 |
| **线宽** | `1px` | 固定线宽 |
| **上边距** | `16px` | 与上方内容间距 |
| **下边距** | `16px` | 与下方内容间距 |
| **宽度** | `100%` | 撑满容器宽度 |

---

## 3. 线条类型 (Line Type)

### 类型 A：实线 (Solid)

+ **描述**：连续的直线，用于明确的内容区块分隔。
+ **适用场景**：
  - 不同功能区域的分隔
  - 列表项之间的分隔
  - 表单字段的分隔
+ **样式**：`border-style: solid`

### 类型 B：虚线 (Dashed)

+ **描述**：断续的线条，用于较弱的内容分隔或特殊含义的区分。
+ **适用场景**：
  - 可选内容的分隔
  - 临时状态的分隔
  - 需要弱化视觉权重的分隔
+ **样式**：`border-style: dashed`

---

## 4. 使用场景示例

| 场景 | 推荐类型 | 说明 |
|------|----------|------|
| 列表项分隔 | 实线 | 明确的条目边界 |
| 表单字段分隔 | 实线 | 清晰的输入区域划分 |
| 内容区块分隔 | 实线 | 大块内容的视觉断点 |
| 可选项分隔 | 虚线 | 表明内容的可选性 |
| 临时/待确认内容分隔 | 虚线 | 传递"待处理"的视觉暗示 |

---

## 5. 设计 Token 映射 (Design Tokens)

+ **颜色 (Color):** `#F5F5F5` (Black NO.2)
+ **线宽 (Width):** `1px`
+ **间距 (Spacing):** `16px` (上下统一)
+ **线条类型:**
  - Solid: `solid`
  - Dashed: `dashed`

---

## 6. 组件代码示例

### CSS 实现

```css
/* 实线分割线 */
.divider-solid {
  border-top: 1px solid #F5F5F5;
  margin: 16px 0;
}

/* 虚线分割线 */
.divider-dashed {
  border-top: 1px dashed #F5F5F5;
  margin: 16px 0;
}
```

### React 组件示例

```jsx
const Divider = ({ type = 'solid' }) => {
  const dividerStyle = {
    borderTop: `1px ${type} #F5F5F5`,
    marginTop: '16px',
    marginBottom: '16px',
    width: '100%'
  };
  
  return <div style={dividerStyle} />;
};

// 用法
<Divider type="solid" />  // 实线
<Divider type="dashed" /> // 虚线
```

---

## 7. 注意事项

1. **避免过度使用**：分割线应服务于内容层级，而非装饰。过多分割线会增加视觉噪音。
2. **保持一致性**：同一页面中，相同场景应使用相同类型的分割线。
3. **间距统一**：所有分割线的上下间距保持 16px，确保视觉节奏一致。
4. **与留白配合**：在某些场景下，纯留白比分割线更优雅，优先考虑内容本身的层级关系。
