# 扫描框组件 (Scan Input)

## 1. 尺寸 (Dimensions)

- **宽度：** `456px`
- **高度：** `60px`
- **内边距 (Padding)：** 左右 `16px`（对应设计系统 Gap: 16px）

## 2. 背景 (Background)

- **背景色：** 使用 Color-Functional-Black 系列 NO.1
- **Token：** `bg-black-1`
- **色值：** `#FFFFFF`

## 3. 边框 (Border)

- **边框样式：** solid
- **边框宽度：** `1px`
- **聚焦宽度：** `1px`
- **边框颜色：** 使用 Primary 系列 NO.6 (主色调)
- **Token：** `border-primary-6`
- **色值：** `#6445D1`

## 4. 圆角 (Radius)

- **圆角半径：** `6px`

## 5. 图标 (Icons)

- **尺寸：** `24px × 24px`
