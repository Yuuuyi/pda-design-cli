# 步进器 (Stepper)

用于数量增减操作，如购物车商品数量调整、表单数值输入等场景。

---

## 何时使用

**用这个组件，当：**
- 需要对数值进行精确的 +1/-1 调整
- 数值有上下限（如购物车数量，最小 0，最大受业务限制）

**不要用这个组件，当：**
- 需要自由输入数值 → 用 InputField
- 需要展示固定数值 → 用普通文本

---

## 一、组件尺寸

| 属性 | 值 |
|---|---|
| **组件宽度** | `146px`（固定） |
| **组件高度** | `40px`（固定） |
| **图标按钮尺寸** | `40px × 40px`（左右各一） |
| **数值区域宽度** | `146px - 40px - 40px = 66px` |
| **数值区域内边距** | `6px 8px` |

## 四、状态

### 4.1 激活态（数值 > 0）

- 数值颜色：`Color-Black NO.6`（`#333333`）
- 图标颜色：`Color-Black NO.6`（`#333333`）
- 交互：减号/加号按钮均可点击

### 4.2 禁用态（数值 = 0）

- 触发条件：当前数值为 `0` 时，步进器进入禁用态
- 数值颜色：`Color-Grey NO.3`（`#D6D6D6`）
- 减号图标：置灰处理，颜色为 `Color-Grey NO.3`（`#D6D6D6`）
- 加号图标：保持激活态（`#333333`），仍可点击
- 说明：禁用态仅作用于减号按钮，0 是业务下限，不可再减

## 五、交互动效

|---|---|
| **过渡时长** | `200ms` |
| **缓动函数** | `ease-out` |

颜色和透明度变化均使用 200ms ease-out 过渡。

---

## 六、约束与边界

1. **宽度固定**：组件总宽度 `146px`，不支持伸缩
2. **数值显示范围**：最大显示 `9999`，超出后显示 `9999+` 或按业务规则处理
3. **数值精度**：仅支持整数（不支持小数）
4. **最小值**：业务下限为 `0`，不可低于此值
5. **最大值**：由业务侧定义（如库存上限），组件本身不硬编码上限
6. **初始值**：由业务侧传入，组件不预设默认值

---

## 七、相关组件

| 组件 | 关系 | 说明 |
|---|---|---|
| InputField | 相似 | InputField 用于自由文本输入，Stepper 用于精确数值增减 |
| NumberInput | 替代 | 如需同时支持输入框手动输入 + 步进按钮，考虑 NumberInput 组合组件 |
| Tag | 无 | Stepper 不涉及标签展示，两者无关联 |
